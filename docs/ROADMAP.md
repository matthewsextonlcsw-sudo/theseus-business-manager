# Roadmap

Built in the open, in this order.

## 1. Knowledge graph v1.2

Expand the original 25-topic graph so it can run a studio, not just advise one:

- **The business itself:** a profile topic built from the studio's public service facts, so answers use real offers and real limits
- **Running it:** operating rhythm, decision rights, cash and collections, project delivery, scope and change requests, capacity, CRM upkeep, speed to lead
- **What a local studio sells:** local visibility, reviews and reputation, managed AI delivery, rules for regulated clients
- **Building websites:** build process, design rules, accessibility, performance, QA and launch
- Fixes: one mislabeled relation, three missing links, two weakly connected topics

## 2. Business-manager skills

`run-the-business` (daily brief, weekly review, pipeline upkeep), `use-the-graph` (retrieve and cite the graph), and a decision-rights section for the agent's standing brief.

## 3. Browser

A visible Chrome window with its own profile, driven through a CLI at a person's pace. No stealth plugins and no CAPTCHA solving.

## 4. Website skill and Astro starter

A standard-tier build process with a "never ship" list, a starter template, and QA the agent runs in its own browser (phone, tablet and desktop screenshots, an accessibility scan, a form test, no sideways scroll).

## 5. CRM stack

Twenty CRM, Chatwoot and a small connector, deployed with a reviewed script. Website chats are answered by the local model with the knowledge graph.
